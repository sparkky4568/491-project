# Sample data (mock, invented)

All four conversations are **invented** for demo and testing. No text comes from AnnoMI, CASAA, Aven or any real call. Every file has `"is_mock": true`, and every model id is `mock-model-v0`. None uses provenance `simulated`: Scope Letter Amendment 1 (s4) says simulated conversations are never used.

Each session exists twice, with the same file name:

- `transcripts/` holds the **TranscriptIn**: the sponsor's canonical transcript schema 1.0 (Sponsor Deliverables v1.2 s8) plus our `is_mock`. Raw turns, no codes.
- `scored/` holds the **ScoredSession** (data contract v0.2), the pipeline's expected output, scored by hand.

The numbers are internally consistent, so these files work as test fixtures: `counts` match the codes on coded agent volleys, `measures` match `counts` and `globals`, Table C matches the volley codes, and `issues` match the measures, Table C and Table D the same way the team's Python scorer builds its issue log. The rules they follow are under "Rules the mock data follows" in `docs/DATA_CONTRACT.md`. All four were scored in one mock run, `run-mock-2026-11-05`, so the issue-log `entry_id` sequence runs across the files in session-id order.
